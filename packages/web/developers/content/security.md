# Reporting a vulnerability

If you found a security problem in Tavvit, please tell whoever runs this instance privately first, so it can be fixed before anyone else can use it.

## How

Write to the address in [`/.well-known/security.txt`](/.well-known/security.txt), or in the [legal notice](/imprint). Say:

- what you found, and what someone could do with it;
- how to reproduce it, as briefly as you can;
- how to reach you, if you would like to hear back.

Please do not post it publicly, or report it through the ordinary [report form](/report), which is for content.

## While you look

- Use your own accounts, and test against your own instance where you can: Tavvit is self-hostable.
- Do not read, change or delete anything that is not yours, and stop as soon as you have shown the problem.
- Do not run anything that could take the service down for others.

## What you can expect

An answer as soon as one can be given, and word on when it is fixed. Say so if you would like to be named.

## This is not for

A token you leaked yourself: make a [new one](/developers/bots), which stops the old one at once.
